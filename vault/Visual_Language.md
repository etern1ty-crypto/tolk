# Visual Language

Тёмный, плотный, современный. Не госуслуги, не неоновый казино.  
Glass — только на панелях, не на каждом бабле.

## Dark monochrome (2026-07-15)
Минимализм = **чёрно-белая** палитра. Цветные акценты (mint/ice) сняты с UI.

## Правило цвета (2026-07-26)
**Интерфейс монохромный — люди цветные.**

Единственное место, где цвет разрешён, — то, что человек выбрал сам про себя:
паттерны баннера профиля (`shared/patterns.ts`) и обложки. Всё остальное —
чаты, лента, навигация, кнопки, состояния — строго ч/б.

Почему так, а не «вырезать цвет везде»: приложение обязано быть тихим, но профиль
должен ощущаться живым, а не формой из госуслуг ([[Living_Profiles]]). Это ещё и
отличает нас от Telegram, где цвет разлит по всему UI. Раньше 27 цветных паттернов
существовали как необъяснённое противоречие этому файлу — теперь это осознанное
исключение с границей.

Границы исключения:
- Цвет живёт только в баннере/обложке профиля. В ленте и чатах он не появляется.
- Бренд-цвета VK/Яндекса на экране входа — вынужденное исключение (требования
  провайдеров), держать локально в `AuthScreen.module.css`, не тащить в токены.
- Цвет **никогда** не несёт смысла (статус, ошибка, непрочитанное) — эти состояния
  читаются формой и контрастом, иначе интерфейс разваливается для дальтоников
  и в ч/б теме.
- Ошибки — через `--accent-danger`, не через хардкод.

| Token | Value | Role |
|---|---|---|
| `bg` | `#000000` | Фон |
| `bg.elevated` | `#111111` | Поверхности |
| `text.primary` | `#F5F5F5` | Текст / CTA fill |
| `text.secondary` | `#A3A3A3` | Мета |
| `text.tertiary` | `#737373` | Hint |
| `accent` | `#F5F5F5` | Primary action (white) |
| `text.onAccent` | `#0A0A0A` | На белой кнопке |
| `border.subtle` | `rgba(255,255,255,0.1)` | Hairlines |

## Layout
Лента стены/профиля — **hairline dividers**, не карточки (как X).  
Чаты: list rows + bubbles, без цветного chrome.

## Radius
CTA / FAB / inputs — pill.  
Медиа — ~16.  
Bubbles ~18.

## Type
Inter / system. 12 meta · 15 body · 18–22 title.

## Icons
**lucide-react** only.  
Единый stroke `1.75` (`shared/ui/icons.ts` + `svg.lucide` CSS).  
Sizes: 16 / 20 / 22 / 24.
